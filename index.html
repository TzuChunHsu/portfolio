Who is TzuChun?

I'm a Software Engineer at Case Medical in New Jersey. I joined the team as an intern in February 2025, was promoted to a full-time role, and now work across the whole stack: Laravel web platforms, Python services that connect our business systems, and the data tools behind our hospital software.

I graduated from the New Jersey Institute of Technology in May 2025 with a Bachelor of Science in Information Technology and a 3.775 GPA, specializing in Network and Information Security. Originally from Taiwan, my journey in the United States has broadened my perspective and taught me how to learn fast in a new environment.

What I enjoy most is turning messy, real-world processes into software people can rely on, whether it's a hospital's instrument lists, two systems that don't talk to each other, or a product catalog clinicians need to search in seconds. I'm always happy to connect about software engineering and system integration opportunities.

Projects

Here are some of the projects I have worked on, from production systems at Case Medical to security research at NJIT.

Case Medical - CaseTrak360 & Hospital Data Onboarding
Laravel Vue.js Pusher Python PHP

CaseTrak360 tracks surgical instruments through hospital sterile processing and the OR. I shipped real-time set location with Pusher, label printing, and barcode scan validation, then built the pipeline that onboards each new hospital: a Python converter that turns Word and Excel count sheets into import packages with audit reports, and a PHP importer that loads 13 types of hospital data.

Case Medical - E-Commerce Upsell Tools
Joomla PHP MySQL JavaScript

Smart recommendation features for Case Medical's Joomla store: "Recommended", "Popular", and "Compatible" product modules driven by cookie tracking and SKU-based compatibility data, encouraging cross-selling without changing core code.

Exploring Cybersecurity Vulnerabilities Through Penetration Testing
Kali Linux Metasploit Phishing

Demonstrates how attackers exploit technical and human vulnerabilities through reverse TCP exploits, backdoors, phishing, and malicious Java applets, and how to mitigate each risk to strengthen system security.

Pizza Vote: Pizza Restaurant Finder & Review Platform
Django Google Places API Team Project

A Django web app for pizza lovers to discover nearby pizza places and share their experiences. Built as a team with the Google Places API for map search, plus user accounts, menus, and 1-10 ratings stored in relational models, and an admin panel for managing submissions.

Case Medical - eIFU Product Platform
Laravel 12 PHP 8 MySQL Tailwind Alpine.js

The web platform where clinicians find Case Medical products by part number, keyword, or GS1 barcode and download Instructions for Use in multiple languages. I built it end to end: the catalog data model, a role-based admin console with audit logging, CSV and Excel import/export, and an automatic WebP image pipeline.

Case Medical - CRM & ERP Integration Hub
Python FastAPI REST / XML-RPC APScheduler

Python services that keep Case Medical's business systems in sync. A FastAPI middleware moves SuiteCRM accounts, contacts, leads, and sales activity into ActiveCampaign every 12 hours, and migration tools carry CRM history into Odoo and legacy articles into Joomla 6. Every job supports dry runs, skips duplicates, and writes a report.

Comprehensive DLL Injection Experiment & Detection
Windows 11 API Hooking Malware Analysis

Simulated DLL injection attacks such as CreateRemoteThread and manual mapping on Windows 11, then built a custom detector using API hooking. The study shows how these attacks work, validates the detector, and assesses built-in defenses like UAC.

Design and Implementation of a Distributed Backend System
Python RabbitMQ MySQL

A distributed backend that connects RabbitMQ message queues and MySQL to handle user requests and database operations. Its multi-layer service architecture supports automated monitoring, error handling, and high concurrency.
